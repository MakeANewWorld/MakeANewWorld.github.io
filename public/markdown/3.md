# 能控制天氣的魔法--if判斷! 電腦的真假


&nbsp;&nbsp;上次我們搞定了玩家的血量，這次來玩點更酷的——控制遊戲裡的天氣！
你可能想過，如果能寫程式決定什麼時候下雨、什麼時候晴天，那該有多好玩？
今天我們就要用 `boolean` 和 `if` 來實現這個想法！  

&nbsp;&nbsp;首先，回到我們的 `ExampleMod` 類別。
找到我們上次寫的 `getHealth` 方法（如果還在的話，可以先把它註解掉或刪掉，我們暫時用不到它）。

# **註解是什麼？**

&nbsp;&nbsp;有時候我們寫了一些程式碼，但暫時不想讓電腦執行它，或者想加一些文字說明給自己或其他人看，這時候就要用 `註解`。  

&nbsp;&nbsp;Java 有兩種基本註解方式：

單行註解： 用 `//` 開頭，從 `//` 開始到這一行結束的內容都會被電腦忽略。

```java
// 這是一行註解，電腦會忽略它
float health = 20.0F; // 也可以寫在程式碼後面
```

多行註解： 用 `/*` 開頭，`*/` 結尾，中間的所有內容都會被忽略。
```java
/*
這是多行註解
可以寫很多行
getHealth 方法暫時不用了
public static float getHealth(net.minecraft.entity.player.PlayerEntity entity) {
    return 1;
}
*/
```

好，現在我們要在 `ExampleMod` 類的底部（記得嗎？最後一個大括號 `}` 之前）加入一個新的`方法`，用來決定天氣。

```java
// 這個方法會告訴我們「是不是」應該下雨
public static boolean shouldItRain() {
    // 這裡我們先簡單一點，直接回傳 true，表示「是」，應該下雨
    boolean makeItRain = true; // 這就是 boolean 變數！
    return makeItRain;
}
```

這裡出現了一個新的類型：`boolean`。  
它很特別，只有兩種值：`true`（真）或 `false`（假）。  
就像開關一樣，不是開就是關。我們用它來表達「是」或「否」的狀態。  
我們宣告了一個 `boolean` 變數 `makeItRain`，並給它 `true` 這個值，然後用 `return` 把這個值「送出去」。  

# **`return` 是什麼？**
`return` 用來結束一個方法的執行，並且可以「回傳」一個值。  
就像你問一個問題（呼叫方法），`return` 就是給你的答案。  
我們這個 `shouldItRain` 方法的回傳類型是 `boolean`，所以它必須 `return` 一個 `boolean` 值。  

# **`public static` 是什麼？**
- `public`：表示這個方法可以從任何地方被存取（呼叫）。想像成一個公共電話亭，誰都可以用。  
- `static`：表示這個方法屬於 `ExampleMod` 這個「類別」本身，而不是屬於某個特定的 `ExampleMod` 物件。  
  現在你可能還不太懂「物件」是什麼，沒關係，把它想像成一個可以直接用「類別名稱.方法名稱」來呼叫的工具方法，像是 `ExampleMod.shouldItRain()`。  

&nbsp;&nbsp;接下來，我們需要一個地方來「使用」這個判斷結果。Minecraft 本身會不斷地更新遊戲狀態，我們可以在這個更新過程中加入我們的天氣控制邏輯。

現在我們要修改 `ExampleMixin` 這個檔案。
```java
package com.example.mixin;

import com.example.ExampleMod;
import net.minecraft.server.MinecraftServer;
import net.minecraft.server.world.ServerWorld;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;

// 注意這裡改成 MinecraftServer
@Mixin(MinecraftServer.class)
public class ExampleMixin {

    // 方法簽名也改了，參數是 MinecraftServer 和 CallbackInfo
    @Inject(at = @At("HEAD"), method = "tick")
    private void onServerTick(CallbackInfo ci) {
        // 把 this 轉型成 MinecraftServer，方便使用
        MinecraftServer server = (MinecraftServer) (Object) this;

        // 呼叫我們在 ExampleMod 裡寫的方法
        boolean raining = ExampleMod.shouldItRain();

        // 這就是 if 判斷！
        if (raining == true) { // 如果 raining 是 true...
            // 讓主世界 (overworld) 開始下雨
            ServerWorld overworld = server.getOverworld();
            if (overworld != null) { // 確保主世界存在
                overworld.setWeather(0, 6000, true, false); // 清除天氣時間設0, 下雨時間6000 tick, 開始下雨, 不打雷
                ExampleMod.LOGGER.info("判斷結果：下雨！"); // 在控制台印出訊息
            }
        } else { // 否則 (如果 raining 是 false)...
            // 讓主世界 (overworld) 停止下雨
            ServerWorld overworld = server.getOverworld();
            if (overworld != null) {
                overworld.setWeather(6000, 0, false, false); // 晴天時間6000 tick, 下雨時間設0, 不下雨, 不打雷
                ExampleMod.LOGGER.info("判斷結果：晴天！");
            }
        }
    }
}
```

這邊也許會多出一些東西:  
`if (raining == true)` 這就是關鍵的 if 判斷式！  
`if` 後面接著一對小括號 `()`，裡面放的是「條件」。   
`==`：這是「等於」比較運算子。注意，它跟 =（賦值運算子）不一樣！  
== 用來比較兩邊的值是否相等，結果會是 boolean（true 或 false）。  
所以 `raining == true` 的意思是「變數 `raining` 的值是否等於 `true`？」。  
如果條件為 `true`，電腦就會執行緊跟在 `if` 後面大括號 `{}` 裡的程式碼。  
`else`: 如果 `if` 的條件是 `false`，電腦就會跳過 `if` 的 `{}`，執行 `else` 後面大括號 `{}` 裡的程式碼。  
`else` 是可選的，如果沒有 `else`，條件為 `false` 時就什麼都不做。  

**執行看看！**

現在，用除錯模式啟動遊戲。你會發現：
1. 遊戲裡會一直下雨！
2. IDEA 的控制台會一直印出 "判斷結果：下雨！"。

**試試看修改！**

回到 `ExampleMod.java`，把 `shouldItRain` 方法改成：
```java
public static boolean shouldItRain() {
    boolean makeItRain = false; // 改成 false
    return makeItRain;
}
```
然後，在 IDEA 裡對著 `ExampleMod.java` 的編輯區點右鍵，選擇 `編譯並重新加載文件`。

回到遊戲（不用重開），你會發現：

1. 雨停了，變成大晴天！
2. 控制台開始印 "判斷結果：晴天！"。

**簡化寫法：**

其實 `if (raining == true)` 可以簡寫成 `if (raining)`，因為 `raining` 本身就是 `boolean` 型別。  
同樣 `if (raining == false)` 可以寫成 `if (!raining)`，這裡的 ! 是「否定」運算子，會把 `true` 變 `false`，`false` 變 `true`。  

```java
// 這是更常見的寫法
if (raining) { // 等同於 if (raining == true)
    // 下雨...
} else {
    // 晴天...
}

// 或者這樣判斷是否為 false
if (!raining) { // 等同於 if (raining == false)
    // 晴天...
} else {
    // 下雨...
}
```

## 總結
今天你學會了：  

- `//` 和 `/* */` 這兩種註解的用法。  
- `boolean` 這個只能存 `true` 或 `false` 的基本資料類型。 
- `if` 和 `else` 條件判斷，讓程式可以根據不同的情況執行不同的程式碼。  
- `==` 這個比較運算子，用來判斷兩邊是否相等。  
- `!` 這個否定運算子。  
- `return` 關鍵字用來從方法回傳值。  
- `public` 和 `static` 的基本意義。
